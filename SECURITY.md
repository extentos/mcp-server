# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's ["Report a vulnerability"](https://github.com/extentos/mcp-server/security/advisories/new) form on this repository.

Please do **not** open public issues for security reports.

## Scope

This repository tracks `@extentos/mcp-server` (npm) and its interaction with the Extentos backend and SDKs. Reports about any part of that surface are welcome here.

## More

See the [security overview](https://extentos.com/docs/resources/security) for how Extentos handles credentials, data, and telemetry.
